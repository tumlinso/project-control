# PCU-RUNTIME-IDENTITY/1

`PROJECT_CONTROL_SKILLS_ROOT` is the canonical explicit Skills root. `CODING_WORKFLOW_SKILLS_ROOT` is a temporary compatibility alias with a bounded deprecation warning. Runtime identity includes the resolved Skills root, Todo package/distribution source, expected contract identity, and initialized authority. Missing, skewed, ambiguous, or later rebound identity fails closed. Local-worker and background execution consume the same verified identity without gaining first-class authority.
