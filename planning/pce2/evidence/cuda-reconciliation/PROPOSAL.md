## Decisions

- Preserve every substantive atlas card, chapter, experiment, source capsule, ledger, uncertainty record, and semantic index. Conventional guides and mixed technical routers are also preserved.
- Add explicit roles, stable semantic IDs, lineage, architecture tags, and index-exclusion metadata. Exclude the full atlas and generated representation inventories from normal indexing without excluding explicit reads.
- Retain NEED mappings and prerequisite/evidence edges. Do not flatten mechanistic or speculative design into conventional tuning advice.
- Rename 190 canonical resource files mechanically from unchanged IDs and titles. Preserve all 237 registered semantic IDs and 929 graph edges. Update physical paths, links, manifests and checksums, with reversible path-substitution audits. Preserve the source ZIP and, where no file links require updating, the full compendium byte-for-byte.
- Prefer operational guides for conventional measurement/tuning and canonical/deep references for representation-oriented design. Suppress only exact section duplicates, retaining alias provenance. Bound focused expansion while preserving broad synthesis and continuations.
- Replace only top-level retrieval-script/context-selection guidance with Project Control usage. Retain controller execution, evidence/artifact handling, GPU interlocks, and all legacy technical decision rules. There is insufficient evidence for safe substantive deletion or consolidation.

## Acceptance

Audit unique ID resolution, unchanged graph relationships, internal links, content hashes after inverse path substitutions, and independent Todo/runtime identities. Topic-presence checks are answerability proxies, not answer-correctness assessments.
