# Accepted program basis

The requested endpoint is one Project Control product with a strong internal workflow authority, not a rewrite of Todo semantics or a monolithic merge of every tool. The donor kernel is relocated and differentially qualified before new behavior is introduced. Existing durable state stays in place.

Cpp-context-compiler remains separate and standalone. Its evidence is consumed through a pure versioned read seam; canonical C++ remains source authority. Native workflow state, Git/source facts, executor state and measured performance retain distinct authority meanings.

Work requirements remain model-independent. Codex configuration chooses available models and effort. Deep MCP exploration should be delegated to a bounded research role when it prevents expensive duplicated context; the parent retains decisions and checks decisive evidence. Cost/latency savings must be measured, not asserted from a model name.

This package captures the agreed design for later execution. Provisional module spelling and task granularity may be refined through the authoritative workflow while preserving the acceptance conditions, single-authority boundary, permissions, evidence and safe integration order. See the numbered design documents for the implementable details and explicit stop line.
