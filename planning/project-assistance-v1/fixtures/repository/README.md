# Synthetic engineering fixture

This small repository supplies source-reading, navigation and testing examples.
All measurements in `synthetic-results.json` are invented fixture data, not
measurements of any machine, GPU, biological system, or production code.

Current limits live in `demo/budgets.py` and are used by `demo/controller.py`.
Historical guidance is labeled in `docs-old.md`.
The demonstration skill has its own entry point under `skills/demo-skill/`.
