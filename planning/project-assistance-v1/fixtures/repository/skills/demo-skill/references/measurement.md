# Measurement prerequisites and limits

Use the same workload, correctness requirements and comparable runtime conditions
for baseline and candidate. Report preparation separately and include it in the
total-cost conclusion. Record versions, inputs and uncertainty. A synthetic table
is not an actual hardware measurement and does not establish universal speedup.

Architecture-specific hardware qualification would require the deliberately
unavailable external-hardware.md reference. Report its absence rather than inventing
GPU behavior or claiming that this fixture qualifies a production mechanism.
