# NONatlas CUDA metadata staging

These are candidate files under the root's `PC-PCE2-RUNTIME` claim. The generator
never writes into the source skill. The atlas worker owns its separate corpus
manifest and all atlas IDs.

Regenerate:

```bash
python packaging/cuda-reconciliation/cuda-metadata/generate_stage.py --source /home/tumlinson/.agents/skills/cuda --output packaging/cuda-reconciliation/cuda-metadata/stage
python -m unittest discover -s packaging/cuda-reconciliation/cuda-metadata -p 'test_*.py' -v
```

The root may install the staged `SKILL.md` and `.project-control-corpus.json`
after review. Before installation, verify every `source_sha256` in
`stage/receipt.json` against the current source bytes. If final integration
updates `assets/cuda-markdown-manifest.json`, rebind that resource's SHA and byte
count to the final generated bytes. Do not run this generator against an already
edited `SKILL.md`; it deliberately requires the original retrieval preimage.

Only the guide retrieval command and its guidance paragraph change in `SKILL.md`;
`skill-retrieval.diff` shows the entire edit. All other corpus text stays intact,
including the legacy router and substantive Volta route/topology advice.

Metadata roles are explicit and path-bounded. Architecture labels come from
architecture directories or `v100`/`volta` filename tokens. Generic references
remain neutral. No inspected NONatlas file is a pure inventory, so mixed routers
and procedural registries retain `operational_guide` roles. The generated asset
has `generated` role and `index_excluded: true`.

Relationships represent literal local inline Markdown links and exact backtick
Markdown paths between known NONatlas resources. Backtick targets must resolve
unambiguously against the referring parent or CUDA root. Ambiguous or unresolved
paths are recorded in the receipt and produce no edges. No prerequisite,
lineage equivalence, or atlas link is inferred.
`validation.log`, `validation.json`, and `stage/receipt.json` retain focused test,
identity, deterministic-output, and byte-preservation evidence. These checks do
not qualify final installed Project Control retrieval; the root owns that check.
