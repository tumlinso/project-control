# Shared knowledge, independent applications

Project Control helps an external agent understand software. Project-Lab helps it conduct controlled experiments. They consume shared packages and own separate application state.

| Component | Owns |
| --- | --- |
| Project Control | Registration, development queries, inspection, profile presentation and Todo adapters. |
| Project-Lab | Experiment scopes, captured inputs, proposals, candidates, measurements and recovery. |
| `project-source` | Source identities, exact reads, discovery, indexes, structural providers and bounded context. |
| `project-evidence` | Artifact identities, immutable observations, provenance, relationships and attributed assessments. |
| Device Scheduler | Resource admission, supervised jobs and physical cleanup receipts. |
| Todo Orchestrator | Plans, tasks, workflow, verification and acceptance. |

The shared packages import neither application, Todo nor inference. A project needs no Todo authority for source retrieval. An evidence index can reference an owner without becoming a second authority for that owner's decisions.

## Useful context with honest support

Parser-resolved calls, declarations, applicable guidance and textual mentions are different observations. Results preserve those distinctions and report ambiguity, freshness and gaps. A test name mentioned in source does not establish that it passed or covers a behavior.

Durable evidence, expiring response packets and advisory notes have different meanings and lifetimes. Assessments identify their authors and criteria; model-generated notes remain advisory even when they cite genuine observations.

The remote Observer gets relevant source bundled with context. Local/Codex gets dense guidance and precise locations. Both express the same intent through selected targets, relationships, revisions, ranges and budgets. `overview` introduces a project; `frontier` explains current work; `delta` covers changes/history; `context` assembles selected support.

## Preserved history

The assistance archive preserves the former Inquiry, investigator, attention and inference implementations. Project-Lab records extraction provenance. Historical-store readers operate on copies without automatically resuming interrupted work or promoting suggestions to proof.
